# 地图图层修复

修复 Crusader 1.41 和 Extreme 1.41 中的两个错误：相连的地面可能被划分成多余的寻路区域；
在没有合适地块时，护城河选择逻辑可能向数组范围之外写入数据。
本模块不会提高 1000 个区域的上限，也不会改变部队选择从护城河哪一侧接近的方式。

需要 UCP3 3.0.7 或更新版本。在启动器中启用模块，然后重启游戏；没有额外设置或按钮。
多人游戏中的所有玩家必须使用相同的模块版本和设置。播放录像时应使用录制时的配置。

实验性预览版：两个游戏版本的自动检查均已通过，但实际游戏、存档读写及多人游戏测试
尚未完成。尚不能证明本模块可以解决所有工人卡住或游戏变慢的问题。测试前请备份存档。
