# Corrections des couches de la carte

Corrige deux erreurs dans Crusader 1.41 et Extreme 1.41 : un terrain continu peut
être divisé en régions de déplacement inutiles, et la sélection des douves peut
écrire hors de son tableau lorsqu'aucune case ne convient. La limite de 1 000
régions et le choix du côté des douves à aborder restent inchangés.

Nécessite UCP3 3.0.7 ou une version ultérieure. Activez le module dans le lanceur
et redémarrez le jeu ; aucun réglage ni bouton supplémentaire. En multijoueur,
tous doivent utiliser la même version du module et les mêmes réglages. Lisez les
replays avec la configuration utilisée lors de leur enregistrement.

Version expérimentale : les vérifications automatisées réussissent sur les deux
versions du jeu ; les tests en jeu, de sauvegarde/chargement et en multijoueur
restent à effectuer. La correction de tous les ouvriers bloqués ou ralentissements
n'est pas démontrée. Conservez une copie de vos sauvegardes avant les tests.
